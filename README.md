# CivicAI - AI Election Learning Platform

CivicAI is an AI-powered interactive election learning platform for voter education, quizzes, simulations, misinformation checks, and civic awareness.

## Features

- AI Election Tutor
- Voting Simulator
- Candidate Comparison
- Fake News Detector
- Manifesto Analyzer
- Bias Detection
- Dynamic Quiz Lab
- Analytics Dashboard
- Profile and theme settings

## Tech Stack

- React
- Vite
- TypeScript
- Gemini API
- LocalStorage

## Run Locally

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in the project root:

```env
VITE_GEMINI_API_KEY=PASTE_YOUR_GEMINI_API_KEY_HERE
VITE_GOOGLE_CLIENT_ID=PASTE_YOUR_GOOGLE_CLIENT_ID_HERE
VITE_GEMINI_MODEL=gemini-2.5-flash
```

Do not commit your real `.env` file.

## Disclaimer

This app is for educational purposes only. It does not provide official voting advice.
